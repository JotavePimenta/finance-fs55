Digital Finance - Dashboard
Objetivo do projeto:

O projeto ajuda o usuário a organizar seu orçamento mensal e visualizar receitas, despesas e saldo de forma simples, tornando a gestão financeira mais consciente e acessível.

Tecnologias utilizadas:

Next.js 16.2.3 — framework React para aplicação web com rotas e SSR/SSG.
React 19.2.4 — biblioteca de UI para componentes.
React DOM 19.2.4 — integração React com o DOM do navegador.
Tailwind CSS 4 — utilitários CSS para estilização rápida.
Ant Design 6.4.3 — biblioteca de componentes de interface.
Axios 1.15.0 — cliente HTTP para chamadas de API.
JSON Server 0.17.4 — servidor fake para dados locais/API de desenvolvimento.
Cypress 15.15.0 — testes end-to-end.
ESLint 9 + eslint-config-next 16.2.3 — lint e regras de qualidade de código.
@phosphor-icons/react 2.1.10 — ícones para interface.
Resumo:

Aplicativo financeiro desenvolvido em Next.js para ajudar o usuário a controlar o orçamento pessoal. O sistema oferece um painel central com visualização de receitas, despesas e saldo, facilitando decisões financeiras mais conscientes.

A solução usa React para interface, Ant Design e Tailwind CSS para layout, Axios para chamadas de dados e JSON Server como backend local de desenvolvimento. Também inclui suporte a testes com Cypress e análise de código via ESLint.
